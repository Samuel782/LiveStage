# Feature Tour — a demo show for testing everything

`shows/Feature Tour.livestage` is generated by a small program, with its own licence-free media:
tones, a pad loop, a title card, a lower third, a 5-page PDF deck, a PNG image sequence and a
10-second countdown movie.

```bash
cargo run --release -p livestage_video --features ffmpeg --example feature_tour -- shows --force
cargo run --release --features ffmpeg -- "shows/Feature Tour.livestage"
```

Without `--features ffmpeg` the show is still built, minus the movie cue (10).

**Before you start**
- **Audio** goes to your default output device. Stems: *Backing Tracks* → outs 1-2, *Click* →
  3-4, *In-Ear Mix* → 5-8 (Audio mixer tab). With a stereo interface you'll hear only outs 1-2;
  repatch the Click stem to 1-2 to hear it.
- **Outputs** open as windows, not fullscreen: *Main Screen*, *Confidence Monitor*, and *Projector*
  (with warp, blend and mask set up). Assign them to real screens in the **Display routing** tab.
- **DMX** is sent to `127.0.0.1` only (sACN universe 1, Art-Net 0:0:1). Point it at a node in the
  **DMX** tab, then press *Apply DMX configuration*.
- **OSC** (UDP 53100) and **WebSocket** (TCP 8765) are on, for this computer only.

| 11 | **Image sequence** loop on the Projector: see the keystone, edge blend and masked strip | Projector window |

| 13 / 14 | **Lighting effects**: rainbow + dimmer chase, mover circle | Lighting → Effects |

| 16 / 17 | *Disarmed*: MIDI note out (needs a port), NDI input (set a real source name) | — |
| 18 | **Colour** wash on the Projector | Projector window |

**Transport keys:** Space = GO, Esc = panic, ↑/↓ move standby, P = pause all, R = resume all,
⌘I = import, ⌘, = settings.

## Timecode Show list

Its cues trigger at 01:00:00:00 (blue), 01:00:04:00 (text on the confidence monitor),
01:00:08:00 (red) and 01:00:12:00 (stops the clock). Start the clock with cue 21, the header's
**Start**, or OSC `/livestage/timecode/start`. To try external timecode, switch the source in the
header (MTC, LTC or Art-Net) and send code from another machine.

## Lighting tab

- 4 RGBW pars, 2 moving heads and a house-light dimmer, placed on the stage plot.
- **Palettes:** Warm white, Deep blue, Red, Magenta, Centre stage, Audience, Full, Tight beam.
- **Submasters:**
  - Pars: additive.
  - Strobe: 1–15 Hz.
  - Movers: an inhibit, starting at full.
  - House lights: starts at 60 %.
- **Effects:** Rainbow chase, Mover circle, Dimmer chase.
- **Grand master** and **DBO** (blackout) are on the right.
- The **pixel map** samples the Main Screen into a 32×8 LED grid on universe 2. Watch its heatmap
  in the DMX tab while cue 1 or 10 plays.
- **Frame sync:** sACN sync universe 7000 and ArtSync are on.

## Remote control

```bash
# OSC (UDP 53100): fire cue 9, next slide, cart 1 pad 6, submaster 1 to 80 %
python3 -c "
import socket,struct
def osc(a,*args):
    pad=lambda b:b+b'\0'*(4-len(b)%4)
    t=','+''.join('f' if isinstance(x,float) else 'i' for x in args)
    return pad(a.encode())+pad(t.encode())+b''.join(struct.pack('>f' if isinstance(x,float) else '>i',x) for x in args)
s=socket.socket(socket.AF_INET,socket.SOCK_DGRAM)
for m in [osc('/livestage/go/9'),osc('/livestage/slide/next'),osc('/livestage/cart/1/pad/6'),osc('/livestage/sub/1',0.8)]:
    s.sendto(m,('127.0.0.1',53100))"
```

| OSC address | Action |
|---|---|
| `/livestage/go`, `/livestage/go/<n>` | GO / fire cue n |
| `/livestage/stop [fade s]`, `/livestage/panic [1]` | stop all / panic (1 = hard) |
| `/livestage/slide/next`, `/slide/prev`, `/slide <n>` | slides |
| `/livestage/cart/<c>/pad/<p> [0/1]` | cart pads (0 releases hold pads) |
| `/livestage/sub/<n> <0–1>`, `/sub/<n>/flash`, `/gm <0–1>`, `/blackout [0/1]`, `/fx/<n> [0/1]` | lighting |
| `/livestage/timecode/start`, `/stop`, `/locate "01:00:04:00"` | timecode |

**WebSocket (TCP 8765)** needs a token: go to **Settings → Security → Issue token**. Then connect
to `ws://127.0.0.1:8765/?token=<token>` and send JSON such as `{"cmd":"go_cue","number":"9"}` or
`{"cmd":"set_outputs_fullscreen","enabled":true}`.

## Edit things

- **Inspector tabs:** General, Timing, Action and Triggers.
- **Timeline:** drag items or their edges to retime them. Snap is to the 120 BPM beat.
- **Edit / Live** (top left) locks editing for the show.
- **Display routing:** warp grid, masks (double-click adds a point, right-click removes one) and
  edge blend.
- **Settings:** appearance, audio device and buffer, network, MIDI, security, timecode outputs
  (MTC, LTC, Art-Net).
- **Import:** drag files onto the window or press ⌘I. Audio, video, images, PDF and PPTX are
  supported.
